# 保种台效果图（静态原型）

这组图是 [`../pt-feature-proposal.md`](../pt-feature-proposal.md) 中 5 个 PT 方向的**视觉原型**，用来先把「长什么样」定下来，再决定实现顺序。

- **不是产品代码**：`pt-center.html` 是一份自包含的静态 HTML/CSS，只用于出图，不接入后端、不进入构建。
- **样式对齐现有 SeedArk**：沿用暗色 liquid-glass（半透明面板 + 顶部/侧边玻璃条）、主色 `#0a84ff`、圆角 20–22px 面板 / 16px 卡片 / 10–12px 控件、Apple HIG 字号层级与 `PingFang SC / Microsoft YaHei` 字体栈。
- **数据是假数据**：站点名、种子名、体积、上传量均为演示值，仅用于展示信息密度和层级。

## 重新出图

仓库里没有引入截图依赖，直接用本机 Chrome/Edge 的无头模式即可：

```bash
# 桌面画面（1600×1000，1.5x 输出 2400×1500）
chrome --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1.5 --window-size=1600,1000 \
  --virtual-time-budget=1600 \
  --screenshot="docs/mockups/01-pt-overview.png" \
  "file:///<repo>/docs/mockups/pt-center.html?s=overview"

# 移动端（1000×1000 画板，手机壳居中）
chrome --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1.5 --window-size=1000,1000 \
  --virtual-time-budget=1600 \
  --screenshot="docs/mockups/07-mobile.png" \
  "file:///<repo>/docs/mockups/pt-center.html?s=mobile"
```

总览拼图用 Pillow 把 6 张桌面图缩到 800×500 后拼成 3×2。

## 画面逐张说明

### 01 PT 概览
- 主卡片「本周可释放 1.84 TB / 38 颗种子」+ 7 日柱状图，绿色今天的柱子。
- 4 个指标卡：做种总量、30 天上传、平均效率、H&R 风险（橙色告警态）。
- 5 张站点卡：站点色点、种子数、体积、30 天上传、分享率、迷你占比条。
- 底部左「高价值保种」榜单（体积 / 30 天上传 / 效率 / 价值分），右「最近可释放」按日期列出。

### 02 释放日历
- 顶部 4 个汇总：今天 / 本周 / 未来 30 天 / H&R 风险。
- 月历格子：绿色=可释放、蓝色=待达标、橙色=H&R 风险、灰色=规则缺失或待定；今天有蓝色描边。
- 右侧当日清单：勾选、名称、站点、原因（已达 30 天 / 分享率）、体积。
- 底部明确标注：**只是预计，不会自动执行；删除前再次校验做种时长与 H&R**。

### 03 资产台账
- 4 个汇总：做种体积、30 天上传、平均效率、零上传种子。
- 筛选：按种子 / 按站点、全部 / 有上传 / 零上传 / 高价值 / H&R 风险、搜索、CSV 导出。
- 主表列：体积、做种时长、30 天上传、效率、最后上传、价值分（进度条）。
- 右侧：站点体积分布 + 清理建议，其中 **H&R 风险明确写“不要删，优先补种”**。

### 04 种子档案库
- 顶部：档案条目数、占用、保留策略。
- 左列表：数据还在 / 数据已删 / 无种子文件三种状态；当前选中项高亮。
- 右详情：可复活状态、最后分享率、累计上传、删除时间、数据目录、文件列表。
- 按钮：复活到 qBittorrent、下载 `.torrent`；底部提示**种子含 passkey，请勿公开分享**。

### 05 同内容矩阵
- 汇总：同内容分组数、重复占用、可合并/可暂停组数。
- 分组卡：4 个副本、站点标签、每站下载器/状态/累计上传。
- 页脚给出结论：重复占用多少、跨几台下载器、可释放多少；近似匹配会提示“建议核对文件列表”。

### 06 发种工作台
- 三步条：选择文件 → 生成资料 → 检查发布。
- 左：已建种文件、MediaInfo 标签、4 张截图占位、模板选择、发布前检查（7/7）、最近发布。
- 右：BBCode 预览（含 `[hide]MediaInfo[/hide]`）、生成发布包 / 复制 BBCode。
- 底部注明：**v1 只生成资料包，不自动上传站点**。

### 07 移动端
- 左侧品牌与三条能力说明，右侧 390×844 手机壳。
- 手机内：本周可释放主卡 + 柱状图、4 个指标、站点分布、底部四页签（概览 / 日历 / 台账 / 档案）。
- 发种在移动端只做查看/复制，截图任务提示到桌面端执行（与提案 4.3 一致）。

## 边界

- 原型只表达**信息架构与视觉方向**，不代表最终字段、文案和交互细节。
- 所有释放估算都只是“预计”，没有自动删种、没有签到刷流、没有站点数据大屏，保持与 MoviePilot 的边界。
- 档案库的复活动作在真实实现中需要二次确认并校验本地数据；原型只展示入口。
